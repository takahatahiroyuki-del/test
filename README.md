# 店舗開発 タスク管理システム

## 必要なもの
- Node.js 16 以上（https://nodejs.org からダウンロード）

## セットアップ手順

### 1. フォルダを社内サーバーに置く
このフォルダ（store-app）をまるごとサーバーの任意の場所にコピーしてください。

### 2. 依存パッケージをインストール（初回のみ）
```
cd store-app
npm install
```

### 3. サーバーを起動する
```
node server.js
```
または
```
npm start
```

起動すると以下のように表示されます：
```
✅ 店舗開発タスク管理サーバー起動
   → http://localhost:3000
```

### 4. ブラウザでアクセス
- 起動したマシン上: http://localhost:3000
- 社内ネットワーク経由: http://[サーバーのIPアドレス]:3000
  例: http://192.168.1.100:3000

### 5. チームメンバーへの共有
サーバーのIPアドレスを確認して、チーム全員に上記URLを共有してください。
全員が同じURLにアクセスすれば、同じデータをリアルタイムで共有できます。

---

## ポート番号を変えたい場合
```
PORT=8080 node server.js
```

## Windows でサーバーを常時起動したい場合
pm2 などのプロセスマネージャーを使うと便利です：
```
npm install -g pm2
pm2 start server.js --name store-tasks
pm2 save
pm2 startup
```

## データの場所
`data/db.json` にすべてのデータが保存されています。
バックアップを取る場合はこのファイルをコピーしてください。

## フォルダ構成
```
store-app/
├── server.js        ← サーバー本体
├── package.json     ← 設定ファイル
├── data/
│   └── db.json      ← データ保存ファイル（自動生成）
└── public/
    └── index.html   ← アプリ画面
```
